Understanding Promises in JavaScript

By Gaurav S. • Oct 26, 2023 • JavaScript Web Development

Promises are a fundamental part of asynchronous programming in modern JavaScript. This tutorial will walk you through what Promises are, how they work, and how to use them effectively to manage async operations and avoid callback hell. 

const myPromise = new Promise((resolve, reject) => {
  // Asynchronous operation here
  setTimeout(() => {
    const success = true; // Simulate success/failure
    if (success) {
      resolve("Operation succeeded!");
    } else {
      reject("Operation failed.");
    }
  }, 1000);
});

myPromise
  .then(message => console.log(message))
  .catch(error => console.error(error));
